# 🀄 台灣麻將（Taiwanese Mahjong）

一個可以直接在瀏覽器玩的台灣麻將（16 張）遊戲。你對三個電腦玩家，整個遊戲只有一個 `index.html` 檔，不需要安裝、不需要伺服器，也沒有任何外部套件。

## 如何遊玩

- **線上玩**：部署到 GitHub Pages 後，直接打開網址即可（部署方式見下方）。
- **本機玩**：下載 `index.html`，用瀏覽器雙擊開啟，連網路都不需要。

### 遊戲流程

1. **擲骰定莊**：按「擲骰子」擲三顆骰子，從你開始逆時針數點數（1 你、2 下家、3 對家、4 上家），數到的人當莊。
2. **洗牌、發牌**：每人 16 張，莊家先摸牌。
3. **輪流摸打**：座位順序為逆時針，你在畫面下方，下家在右、對家在上、上家在左。
4. 點手牌打出一張。別人打牌時，如果你可以吃、碰、槓或胡，畫面會出現對應的按鈕，不想要就按「過」。
5. 胡牌後會顯示台數明細和輸贏，按「下一局」繼續。牌牆剩 16 張（留底牌）時仍未胡牌，就是流局。

### 操作按鈕

| 按鈕 | 出現時機 |
| --- | --- |
| 胡 | 別人打出的牌可以讓你胡牌 |
| 自摸 | 你摸牌後手牌已經胡牌 |
| 碰 | 手上有兩張相同的牌，別人打出第三張 |
| 吃 | 只能吃上家（你左邊的玩家）剛打出的牌，有多種吃法時會分開列出 |
| 槓 | 明槓（別人打出，你手上有三張）、暗槓（手上四張）、加槓（已碰的牌再摸到第四張） |
| 過 | 放棄這次吃、碰、槓、胡 |

## 規則與計分

### 基本規則

- 一副牌 144 張：萬、筒、條各 36 張，字牌 28 張（東南西北中發白），花牌 8 張（春夏秋冬、梅蘭竹菊）。
- 花牌摸到時自動亮出，並從牌牆補牌。
- 胡牌牌型：五組面子（順子或刻子）加一對將牌。
- 槓牌後從牌牆另一端補一張牌，補牌後胡牌算槓上開花。

### 莊家與圈風

- 莊家胡牌或流局：連莊。
- 閒家胡牌：換下家當莊，連莊數歸零。
- 莊家繞完一圈回到起莊的座位後，圈風依序換為東、南、西、北。

### 積分

每人起始 1000 分。每局贏家得分為：

```
底 30 分 + 台數 × 每台 10 分
```

- **自摸**：其他三家各付這個金額。
- **別人放槍**：只有放槍的人付。

### 台數

| 台種 | 台數 | 說明 |
| --- | --- | --- |
| 莊家 | 1 | 莊家胡牌 |
| 連 N 拉 N | 2N | 莊家連莊 N 次後胡牌 |
| 自摸 | 1 | |
| 槓上開花 | 1 | 槓牌補牌後自摸 |
| 門清 | 1 | 沒有吃、碰、明槓（暗槓不影響） |
| 花牌 | 每張 1 | 只算與自己座位相同編號的花（座位依莊家順序：莊為 1） |
| 三元牌 | 每組 1 | 中、發、白的刻子（含槓） |
| 圈風 | 1 | 目前圈風的刻子 |
| 門風 | 1 | 自己座位風的刻子 |
| 碰碰胡 | 4 | 全部是刻子加一對 |
| 混一色 | 4 | 只有一種花色加字牌 |
| 清一色 | 8 | 只有一種花色，沒有字牌 |

## 電腦玩家

- 能胡就胡。
- 打牌時依手牌的相連、成對程度評分，優先打出孤立的字牌與邊張。
- 會碰（機率約 35%）、槓（明槓約 50%、自己回合的暗槓或加槓約 60%）。
- 不會吃牌。

## 自訂玩家頭像

預設頭像是表情符號。想換成自己的圖片，把四張圖片放在 repo 的 `img` 資料夾，檔名固定：

| 檔名 | 玩家 |
| --- | --- |
| `img/p0.jpg` | 你 |
| `img/p1.jpg` | 下家 |
| `img/p2.jpg` | 對家 |
| `img/p3.jpg` | 上家 |

- 建議使用正方形圖片，會被裁成圓形。
- 沒放的玩家會繼續使用表情符號。
- 請使用自己的圖片或有授權的圖片，尤其是網站公開的情況下。

## 部署到 GitHub Pages

1. 建立一個 **Public** repo，把遊戲檔案命名為 `index.html`，放在最外層。
2. 前往 **Settings → Pages**，Source 選 **Deploy from a branch**，Branch 選 `main`、資料夾選 `/ (root)`，按 Save。
3. 等一兩分鐘，網址會是 `https://<你的帳號>.github.io/<repo 名稱>/`。

更新遊戲時，重新上傳同名的 `index.html` 覆蓋，等部署完成後強制重新整理（Ctrl+Shift+R）即可。

```
.
├── index.html     # 整個遊戲：HTML + CSS + JavaScript

└── README.md
```

## 技術說明

- 純 HTML、CSS、JavaScript，沒有任何套件或建置步驟。
- 筒子與條子的牌面用 SVG 繪製，花牌使用表情符號圖案。
- 胡牌判斷用遞迴拆牌（先找對子，再找刻子與順子）。
- 版面為四家圍桌：牌河、牌牆在中央，牌牆以疊起來的牌背顯示剩餘張數。
